# Bloom brand

| File | Use it for |
| --- | --- |
| `bloom-logo.svg` | The logo ("Bud") with its gradient. App icons, avatars, favicons. |
| `bloom-logo-mono.svg` | One-color logo, for places that can't show a gradient. |
| `bloom-wordmark-dark.svg` / `-light.svg` | The word "Bloom" alone. Dark text for light backgrounds, light text for dark ones. |
| `bloom-lockup-dark.svg` / `-light.svg` | Logo + wordmark together. The main logo for websites and headers. |

**Colors.** Logo gradient: `#6E56F8` → `#B48CFF` → `#FF8DBF`, bottom to top. Only the logo uses the gradient; the apps use flat Material 3 colors.

**Type.** Google Sans Flex (Open Font License). The wordmark is weight 700, width 112, roundness 100. App headings use the same font with roundness 100.

**Spacing.** In the lockup, the logo is 1.45x the height of the letters, with a gap of 0.38x the letter height.

The files are generated by the scripts in `tools/brand/`.
